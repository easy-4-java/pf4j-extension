# pf4j-extension

独立的 PF4J 扩展组件，提供扩展元数据、扩展点查找、调用异常、动态代理和通用加解密扩展点。

本仓库已移除旧 `ro.fortsoft.pf4j` 与 Spring WebMVC 强绑定实现，统一使用当前 `org.pf4j` 坐标。
